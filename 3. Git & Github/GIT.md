# Git

Esto es un herramienta vital para cualquier programador, ya que es un software de control de versiones

Usamos git para guardar los cambios, ya que si creamos muchos archivos de una sola version es algo jodido ya que es desorganizado y horrible

Tambien nos permite crear un ambiente donde varias personas pueden editar el mismo codigo/archivo y juntarlo

Pero con git seria tedioso, por eso existe github esto nos permite colaborar entre mcuhas personas desde la nube y no desde local
